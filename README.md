# Flipkart Data Analysis Dashboard – Power BI

## 📊 Project Overview

This project is an interactive Power BI dashboard built using Flipkart product listing data. It explores product attributes, pricing, delivery information, payment methods, and seller performance through data visualizations.

The objective is to understand product trends, analyze seller ratings, and explore different product characteristics using Power BI.

## 🛠️ Tools & Technologies

- **Power BI Desktop** – Dashboard development and visualization
- **Flipkart Dataset (CSV)** – Data source
- **MySQL** – Data querying and data preparation
- **Python (Pandas)** – Data cleaning and exploratory data analysis

## 📁 Dataset Information

**Dataset:** `Flipkart_Normal_Comma_Separated`

The dataset contains product and seller information, including:

- Product ID and Product Name
- Brand and Category
- Price and Final Price
- Discount Percentage
- Product Rating and Review Count
- Product Score
- Listing Date
- Payment Modes
- Return Policy and Returnability
- Delivery Days
- Seller Name and Seller City
- Seller Rating
- Shipping Weight
- Product Color

## 📈 Dashboard Visualizations

The dashboard contains three main visualizations:

### 1. Product and Delivery Analysis
- Column Chart
- Examines product attributes such as brand, category, color, and returnability.
- Uses delivery days as the numerical measure.
- Includes discount percentage and final price in tooltips.

### 2. Product Listing and Price Analysis
- 100% Stacked Area Chart
- Explores listing dates and product information.
- Uses payment modes for series comparison.
- Displays price as the numerical measure.
- Includes product score, rating, return policy days, and review count in tooltips.

### 3. Seller Performance Analysis
- Area Chart
- Examines sellers and their respective cities.
- Uses seller rating as the numerical measure.
- Includes shipping weight in tooltips.
